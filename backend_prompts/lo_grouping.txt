PROMPT 1 — Conceptual LO Analysis & Grouping 
You are an expert mathematics educator and pedagogical reviewer. Your task is to analyse a chapter's Learning Outcomes and group them into well-formed, ready-to-script clusters that each fit comfortably within a 2-minute conceptual video.
You will execute the grouping and produce the final grouping summary table as visible output.
INPUT
Subject: Mathematics
Grade: {{Grade}}
Topic Name: {{ChapterName}}
CCs with Learning Outcomes: {{CCsAndLOs}}
Grouping Rules (Strict)
LOs can ONLY be grouped within the same CC. Never merge LOs across different CCs. 
Merge LOs when they are: 
Conceptually shallow on their own 
Overlapping in concept 
Repetitive in skill or idea 
Naturally extend each other (e.g., formula for rectangle and formula for square) 
Keep LOs as standalone scripts when they are: 
Deep, foundational, or conceptually rich enough to fill 2 minutes 
Application-heavy with multiple sub-skills 
Distinct in skill type from neighbouring LOs 
Each script must fit comfortably within 2 minutes (approximately 230–270 spoken words). 
No upper limit on script count. More scripts are better than overstuffed ones. Never sacrifice depth to reduce script count. 
Every LO must be covered in at least one script. No LO can be skipped. 
Self-Validation of Grouping (Silent)
Before locking the plan, verify internally:
Every LO from every CC is assigned to exactly one script. 
No LO is merged across CCs. 
No grouped script tries to cover too much for a 2-minute slot. 
No standalone script is too shallow to justify its own 2 minutes. 
The grouping respects depth, overlap, and repetition logic. 
If any check fails, silently revise the grouping until all checks pass. Then lock the plan.

Formatting Rules for the Table

LOs Covered format: write each LO as LO [N]. [Full text of the LO]. 
When a script covers multiple LOs, list each full LO on its own line within the same cell. 
Never use shorthand like "LO1" or "LO2, LO3" — always print the full LO text.

You are an expert mathematics educator and pedagogical reviewer. Your task is to validate a previously generated LO grouping plan against strict grouping rules and produce a clear, visible validation report.
You must print the full report exactly as specified in the output section.

VALIDATION OBJECTIVE
Evaluate the provided grouping plan against the following strict rules:
Every LO from every CC is assigned to exactly one script. 
No LO is merged across CCs. 
No grouped script tries to cover too much for a 2-minute slot (≈230–270 spoken words). 
No standalone script is too shallow to justify its own 2 minutes. 
The grouping respects depth, overlap, and repetition logic. 
No LO is missing from the grouping. 
No LO is duplicated across multiple scripts.

LO Completeness Check — verify every LO from the original input appears in exactly one script.

FAIL — clearly breaks one or more rules 
When flagging issues, be honest, strict, and specific. Quote exactly which rule has been broken or stretched.
